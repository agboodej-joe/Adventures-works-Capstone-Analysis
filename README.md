AdventureWorks Dataset:
The AdventureWorks dataset was transformed by cleaning and organizing the Sales, Customer, Calendar, and Territory data tables. This included correcting data types, removing unnecessary or duplicate data, standardizing fields, and preparing the tables for proper relationships and analysis in Power BI.

Budget Dataset:
The Budget dataset was transformed by cleaning and standardizing its budget values and month-related fields, correcting data types, and organizing the data so that monthly budget figures could be compared with actual sales. The Month field was prepared for integration with the Calendar table and subsequent analysis.

Overall:
The transformation process converted the raw AdventureWorks and Budget data into structured, consistent, and analysis-ready tables, enabling relationships between the tables and supporting accurate Power BI visualizations and business insights.
